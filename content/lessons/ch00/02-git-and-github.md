# Git と GitHub / GitLab

| | 何か | どこで動く |
| --- | --- | --- |
| **Git** | バージョン管理ツール（コマンド） | 自分の PC |
| **GitHub** | Git リポジトリを置いて共同作業するサービス | インターネット上 |
| **GitLab** | GitHub とほぼ同じ役割のサービス（自社サーバーにも置ける） | インターネット上 / 社内 |

Git は **[[distributed|分散型]]** のバージョン管理システムです。チームの全員が履歴まるごとの **[[repository|リポジトリ]]** を手元に持ち、GitHub などに置いた共有リポジトリ（**[[remote|リモート]]**）と [[push]] / [[pull]] でやりとりします。

GitHub ではブランチの変更を取り込んでもらうときに **[[pull-request|Pull Request（PR）]]** を作り、レビューを受けてからマージします。GitLab では同じものを **Merge Request（MR）** と呼びます。
