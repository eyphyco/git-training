# バージョン管理とは

レポートやプログラムを作っていると、こんな経験はありませんか？

- 「report_最新.txt」「report_最新_本当に最新.txt」… どれが正しいか分からない
- 昨日まで動いていたのに、どこを変えて壊れたのか分からない
- 2人で同じファイルを直して、片方の変更が消えた

**[[version-control|バージョン管理]]** は、ファイルの変更履歴を記録し、いつでも過去の状態に戻したり、複数人の変更をまとめたりするための仕組みです。**Git** は世界で最も使われているバージョン管理システムです。

Git では、作業の区切りごとに **[[commit|コミット]]**（その時点のスナップショット）を作ります。コミットは親のコミットを指していて、つながると「歴史」になります。画面中央の **コミットグラフ** はこの歴史を図にしたものです。

> 💡 画面上の点線の下線が付いた言葉にマウスを乗せる（スマホではタップ）と、詳しい説明が出ます。
