# HEAD と detached HEAD

**[[HEAD]]** は「今どこにいるか」を表す目印で、普段は **ブランチ** を指しています（`HEAD -> main`）。コミットするとブランチが進み、HEAD もそれについていきます。

HEAD がブランチを経由せず **コミットを直接** 指している状態を **[[detached-head|detached HEAD]]** と呼びます。過去の状態を見るのに便利ですが、そこで作ったコミットはブランチに属さないので注意が必要です。

| 書き方 | 意味 |
| --- | --- |
| `HEAD~1` / `HEAD^` | HEAD の1つ前（親） |
| `HEAD~2` | 2つ前 |
| `main~1` | main の1つ前 |
