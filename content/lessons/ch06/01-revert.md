# revert：打ち消すコミットを作る

`git revert <コミット>` は、そのコミットの変更を **逆向きに当てた新しいコミット** を作ります。

- 履歴は消えない（壊れたコミットも、打ち消したコミットも残る）
- コミットが増えるだけなので、push 済みでも普通に push できる

```
git revert --no-edit HEAD
```

> 実 Git では `--no-edit` を付けないとエディタが開き、メッセージ「Revert "..."」を確認・編集できます。このサイトではエディタが開かないので `--no-edit` を付けます（付けなくても既定のメッセージで作ります）。

マージコミットの revert には `-m 1` のように「どちらの親を基準にするか」の指定が必要です（このサイトでは未対応）。
