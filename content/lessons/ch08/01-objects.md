# Git の中身：オブジェクトと refs

`.git` フォルダの中身は、意外とシンプルです。

| もの | 中身 |
| --- | --- |
| `HEAD` | 今いるブランチの名前（`ref: refs/heads/main`） |
| `refs/heads/main` | main が指すコミットの ID（1行） |
| `objects/` | すべてのオブジェクト（圧縮して保存） |
| `index` | ステージの内容 |

**4種類のオブジェクト**

| 種類 | 中身 |
| --- | --- |
| blob | ファイルの中身だけ（名前は持たない） |
| tree | フォルダ1つ分：名前 → blob / tree の ID |
| commit | tree・親・作者・メッセージ |
| tag | 注釈付きタグ |

ID は「中身」の [[hash|SHA-1]] です。このサイトのコミット ID は、本物の Git と同じ計算で作っています（同じ操作をすれば本物と同じ ID になります）。

> 実 Git の `.git/objects` のファイルは zlib で圧縮されているので、`cat` では読めません。中身は `git cat-file -p` で見ます。
