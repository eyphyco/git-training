# clone

`git clone <URL>` は、GitHub などにある **[[remote|リモート]]** リポジトリを、履歴まるごと手元に複製します。

clone すると自動で次の設定がされます。

- リモートが **[[origin]]** という名前で登録される
- `origin/main` など、リモートのブランチの位置を覚える **リモート追跡ブランチ** ができる
- 手元の `main` が `origin/main` を **追跡（upstream）** する

画面の4エリアビューの「リモート」列に、GitHub 側の状態が表示されるようになります。

> 実 Git では `app` というフォルダが作られ、`cd app` で中に入ります。このシミュレータでは今のフォルダに直接展開します。
