# マージ方式3種

GitHub の「Merge pull request」ボタンには3つの方式があります。

| 方式 | main にできるもの | 向いている場面 |
| --- | --- | --- |
| **Create a merge commit** | PR のコミット ＋ マージコミット | 履歴をそのまま残したい |
| **Squash and merge** | PR 全体を1つにまとめたコミット | 細かい作業コミットを main に残したくない |
| **Rebase and merge** | PR のコミットを main の先に付け直したもの | 一直線の履歴にしたい |

チームでどれを使うかは決めておくのが普通です（リポジトリの Settings で許可する方式を選べます）。

比較ビュー（ホームの「⚖️ 比較ビュー」）でも、merge と squash の違いを並べて見られます。
