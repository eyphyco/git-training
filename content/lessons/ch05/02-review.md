# レビューの指摘を反映する

PR では、チームメンバーが差分を読んで次のどれかを返します。

| レビュー | 意味 |
| --- | --- |
| **Approve** | 承認。マージしてよい |
| **Request changes** | 修正してほしい。直るまでマージしない |
| **Comment** | 意見・質問だけ |

修正を頼まれたら、**同じブランチ**でコミットして push します。PR はブランチに紐づいているので、新しいコミットが自動で PR に追加されます。

:::figure{id="pr-flow"}

> 自分の PR は自分で Approve できません（GitHub と同じ）。レビューは必ず他の人にしてもらいます。
