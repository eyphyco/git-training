# ブランチ戦略：GitHub Flow とトランクベース

**[[branch-strategy|ブランチ戦略]]**は「どんなブランチを、どう作って、どこへマージするか」のチームの約束です。このサイトでは、戦略を設定したレッスンでルール違反をすると ⚠️ が出ます。

| 戦略 | 長く使うブランチ | ひとことで |
| --- | --- | --- |
| **GitHub Flow** | main だけ | 短いブランチ → PR → main。main は常にデプロイ可能 |
| **トランクベース** | main（trunk）だけ | 全員がこまめに main に統合。ブランチは数時間〜1日 |
| Git Flow | main と develop | 次のレッスン |
| GitLab Flow | main と環境ブランチ | 第7章の3つ目 |

ホームの「🌿 ブランチ戦略」で、4つの戦略を自由に試せます。
