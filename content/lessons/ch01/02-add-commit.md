# add と commit — 3つのエリア

Git には3つのエリアがあります。

| エリア | 役割 | 移動するコマンド |
| --- | --- | --- |
| [[working-tree|ワークツリー]] | 実際に編集しているファイル | — |
| [[staging-area|ステージ（インデックス）]] | 次のコミットに入れるものを並べる場所 | `git add` で ワークツリー → ステージ |
| リポジトリ | コミット（スナップショット）の保存場所 | `git commit` で ステージ → リポジトリ |

:::figure{id="three-areas"}


なぜ直接コミットせずにステージを挟むのか？ — 「今回のコミットに入れる変更」を選べるようにするためです。10ファイル変えても、関係する3ファイルだけを1つのコミットにまとめられます。

ファイルの状態は [[untracked|未追跡]] → [[staged|ステージ済み]] → コミット済み（[[tracked|追跡中]]）と変わっていきます。
