# リポジトリを作る

Git で管理したいフォルダで `git init` を実行すると、そのフォルダが **[[repository|リポジトリ]]** になります。実体は中に作られる隠しフォルダ `.git` で、ここに全ての履歴が入ります。

画面の見方：

- **中央上：コミットグラフ** — コミットの歴史。今はまだ空です
- **中央下：エリアビュー** — [[working-tree|ワークツリー]] / [[staging-area|ステージ]] / リポジトリ にどのファイルがあるか
- **下：ターミナル** — コマンドを入力。Tab で補完、↑↓で履歴

> 💡 失敗しても大丈夫。右上の「↶ 戻す」でいつでも1つ前に戻れます。
