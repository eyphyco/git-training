# レビューで修正を頼まれた

PR を出すと、レビューで修正を頼まれるのはよくあることです。直し方は2通りあります。

- **修正コミットを足す**：「fix review」のようなコミットを積む。簡単ですが、履歴に「直し」が残ります
- **元のコミットを直す**：`git commit --fixup <コミット>` と `git rebase --autosquash` で、直しを元のコミットに混ぜる。履歴はきれいですが、push 済みのコミットを書き換えるので force push が要ります

このチームは rebase and merge でコミットをそのまま main に並べるので、後者を選びます。

## force push は --force-with-lease で

`--force` は相手のコミットを確かめずに上書きします。`--force-with-lease` は「最後に fetch したときからリモートが動いていないこと」を確かめてから上書きするので、誰かが同じブランチに push していれば **stale info** で止まります。

止まったら `git fetch` して中身を確かめ、必要なコミットを取り込んでから送り直しましょう。fetch した後の `--force-with-lease` は通ってしまう点に注意します。
