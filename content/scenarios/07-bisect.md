# いつの間にか CI が赤い

「いつから壊れていたのか分からない」ときは、`git bisect` で二分探索します。正しかったコミット（good）と壊れているコミット（bad）を教えると、間のコミットを半分ずつ試して原因を絞り込みます。

1つずつ手で確かめる代わりに、**正しければ 0、壊れていれば 0 以外で終わるスクリプト**を `git bisect run` に渡すと、自動で最後まで進めてくれます。

- スクリプトはコミットしなくて構いません。未追跡のファイルは、bisect がコミットを切り替えても残ります
- 原因が分かったら `git bisect reset` で元のブランチに戻ります
- 共有ブランチ（main）の修正は、`git revert` で「打ち消すコミット」を作って PR にします。履歴は書き換えません

（このサイトの bisect run が実行できるのは、hooks と同じ小さなシェルのスクリプトだけです。実機では npm test などのテストをそのまま渡せます。）
