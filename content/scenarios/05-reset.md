# 消してはいけないコミットを reset で消した

`git reset --hard` はブランチもワークツリーも巻き戻す強い操作です。指示の取り違えや打ち間違いで、必要なコミットを消してしまうことがあります。

慌てなくて大丈夫です。コミットは reset の直後も消えずに残っていて、**reflog**（HEAD やブランチが動いた記録）からたどれます。

- `git reflog` で、reset する前の位置（`HEAD@{1}` など）を探す
- `git branch <名前> HEAD@{1}` や `git reset --hard HEAD@{1}` で取り戻す

ただし、**コミットしていない変更**は reflog に残りません。reset --hard の前に、`git status` で消えて困るものがないか確かめる習慣をつけましょう。

（実 Git では、どこからも指されないコミットは一定期間（既定で30日以上）たつと、git gc で本当に消えます。）
